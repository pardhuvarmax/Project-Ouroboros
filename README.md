## Project Ouroboros Blue Pill
> **Project Ouroboros Blue Pill** is an ESP32-powered wireless defense suite that provides hardware defensive protection & detection against Wi-Fi deauthentication, jamming, spoofing, rogue APs, and BLE/Sub-GHz threats, using anomaly detection, active countermeasures, and self-healing to secure personal and IoT networks.
